# Chuleta HARO

Chuleta interactiva de comandos para Hack The Box y laboratorios propios, organizada por situación.

**Web:** https://xaviharollovera.github.io/chuleta/

## Qué incluye

- 114 comandos en 12 categorías: reconocimiento, web, servicios, Directorio Activo, reverse shells, mejorar la shell, transferencia de archivos, escalada en Linux y Windows, crackeo, pivoting y utilidades.
- Variables (`TARGET`, `IP`, `PORT`, `DOMAIN`, `USER`, `PASS`, `HASH`) que se rellenan solas en todos los comandos.
- Buscador, filtros por categoría y botón de copiar en cada comando.
- Favoritos y comandos propios guardados en el navegador.
- Atajos: `/` para buscar y `Esc` para limpiar.

## Uso

Abre `index.html` en el navegador o visita la web. No necesita instalación ni servidor: es una única página estática.

Los favoritos, los comandos propios y las variables se guardan en el `localStorage` del navegador; no se envían a ningún sitio.

## Aviso

Solo para entornos autorizados: Hack The Box, TryHackMe, laboratorios propios o auditorías con permiso.
